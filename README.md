# R Statistics & GLMs

Interactive companion to a 10-part course on R, classical inference, linear models and generalized linear models, built with [Quarto](https://quarto.org) and [quarto-live](https://r-wasm.github.io/quarto-live/) (R running in the browser via webR).

- The written notes are the Obsidian `.md` files (`00 - Course Overview.md`, `01 - Module 1 ...`).
- The interactive pages are `index.qmd` and `M0.qmd`–`M9.qmd`: runnable exercises with hints and solutions, plus a slider-driven "Explore" widget in each module.
- The rendered site is in `docs/`. Rebuild with `quarto render` (needs R with `knitr` and `rmarkdown`).
