7 · Logistic regression

Log-odds and odds ratios, predicted probabilities, ROC/AUC, thresholds, grouped data and separation

Course data (loads automatically; click to see the code)

R runs inside your browser. The first visit downloads R and the packages, which takes 20–40 seconds; after that the browser caches them. Wait for this block to finish before running exercises.

\[\log\left(\frac{p}{1-p}\right) = \beta_0 + \beta_1 x_1 + \dots \qquad p = \frac{1}{1 + e^{-\eta}}\]

  • Odds ratios: exp(β) multiplies the odds per unit of x. Odds are not probabilities: doubling the odds takes p = 0.1 to 0.18 but p = 0.5 to 0.67.
  • Predicted probabilities: predict(fit, newdata, type = "response"), or plogis() of the linear predictor by hand.
  • Confusion matrix: sensitivity = TP/(TP + FN), specificity = TN/(TN + FP), precision = TP/(TP + FP).
  • ROC / AUC: sensitivity vs 1 − specificity as the threshold sweeps; AUC 0.5 = coin flip, 1 = perfect. Performance measured on the training data is optimistic: validate on held-out data.
  • Thresholds: 0.5 has no special status. Choose from the relative costs of false positives and false negatives.
  • Grouped data: glm(cbind(successes, failures) ~ x, family = binomial()).
  • Separation: when x perfectly predicts y, the MLE runs off to infinity (“fitted probabilities numerically 0 or 1 occurred”). Firth’s penalised likelihood (logistf) gives finite estimates.

Explore: thresholds and costs

The model is default ~ balance + income + student. Move the threshold and set how much worse a missed default is than a wrongly declined customer.

viewof th = Inputs.range([0.01, 0.99], {value: 0.5, step: 0.01, label: "Threshold"})
viewof cost_ratio = Inputs.range([1, 50], {value: 20, step: 1, label: "Cost of a missed default ÷ cost of a false alarm"})

At 0.5 the model catches only about a third of defaulters. With a 20:1 cost ratio the cheapest threshold is around 0.05. These are apparent (training-data) numbers; in real work you would choose and evaluate the threshold on held-out data.

Exercises

Q1 — Fit and read a logistic regression

Fit default ~ balance + income + student and report odds ratios with CIs. Interpret balance and studentYes.

fit <- glm(default ~ balance + income + student, family = binomial(), data = Default)
tidy(fit, exponentiate = TRUE, conf.int = TRUE)

balance OR ≈ 1.00575 per dollar: tiny per dollar, but over \(1000 the odds multiply by about 310. `studentYes` OR ≈ 0.5: **holding balance and income fixed**, students have lower odds of default, even though the unadjusted association points the other way (students carry bigger balances). Check `table(Default\)student, Default$default)` to see the reversal.

Q2 — Predicted probability by hand

For a student with balance 2000 and income 40,000: compute η, apply the inverse logit, and check against predict().

eta <- b["(Intercept)"] + b["balance"] * 2000 + b["income"] * 40000 + b["studentYes"] * 1
predict(fit, newdata = data.frame(balance = 2000, income = 40000, student = "Yes"), type = "response")

Both agree to many decimal places.

Q3 — ROC and AUC

Compute the AUC, plot the ROC curve, and find the sensitivity at 95% specificity.

auc(roc_obj)
coords(roc_obj, x = 0.95, input = "specificity", ret = c("sensitivity", "specificity"))

Apparent AUC ≈ 0.950; at 95% specificity the interpolated sensitivity is about 0.715. Both are optimistic until recomputed on held-out or cross-validated predictions.

Q4 — Threshold under asymmetric costs

A missed default costs $10,000; a wrongly declined customer $500. Write the expected cost per customer as a function of the threshold and grid-search it.

fp <- sum(!actual & pred)

The apparent optimum is about 0.05: a miss costs 20× a false alarm, so the model should flag aggressively. Choose thresholds from explicit costs and calibrated probabilities, then evaluate on validation data.

Q5 — Grouped binomial germination experiment

Simulate 50 plots of 20 seeds (control p = 0.4, hormone p = 0.7), fit the grouped GLM, and confirm the long-form (one row per seed) fit gives the same coefficients. The true odds ratio is (0.7/0.3)/(0.4/0.6) = 3.5.

fit_grouped <- glm(cbind(n_success, n_failure) ~ treatment, family = binomial(), data = germ)

The treatmenthormone OR is near 3.5 (a valid 95% CI covers it in about 95% of repeated experiments, not necessarily this one). Grouped and long forms give identical coefficients.

Q6 — Separation and Firth’s correction

x perfectly separates y. See what glm() does, then fit Firth’s penalised model.

The function has the same name as the package: logistf::logistf(). The install line fetches it into your browser the first time (it can take a little while).

fit_firth <- logistf::logistf(y ~ x, data = sep_df)

glm() warns that fitted probabilities are numerically 0 or 1 and returns an enormous slope with an even more enormous SE: with perfect separation the likelihood keeps increasing as the slope grows, so there is no finite MLE. Firth’s penalty (the Jeffreys-prior term) gives a finite, stable estimate. Separation is common with small samples, rare outcomes or many predictors, but can happen at any n.
