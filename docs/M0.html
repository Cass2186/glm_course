Cheat sheet

Topic The thing to remember
Assignment x <- 5. Keep = for named arguments inside function calls.
Types numeric, integer (3L), character, logical (TRUE/FALSE, never T/F), factor, NA. Check with class() and str().
Vectors Everything is a vector; arithmetic is vectorised; shorter vectors are recycled.
Subsetting $ and [[...]] pull a column out as a vector; a single [...] keeps you in data-frame world. x[-1] drops the first element.
Factors Level order sets the reference level. Set it yourself: factor(g, levels = c("WT", "HET", "KO", "RESCUE")). Use droplevels() after filtering.
Formulas y ~ x + z main effects; y ~ x * z adds x:z; y ~ . all other columns; - 1 removes the intercept.
Pipes a |> f() |> g() reads left to right and means g(f(a)).
Functions f <- function(x, na.rm = TRUE) { ... }; the last expression is returned. ... passes extra arguments along.
NA Viral: mean(c(1, NA)) is NA. Test with is.na(), never == NA.
Packages install.packages() once, library() each session, or pkg::fun() without loading.
Help ?mean, ?"[", ??anova.

Common gotchas

Gotcha Fix
Numeric columns import from CSV as character str(df) to check types; type.convert()
Factor levels in the wrong (alphabetical) order factor(x, levels = c(...)) explicitly
mean(x) returns NA Add na.rm = TRUE
Single [...] returns a data frame, not a vector Use [[...]] or $
Comparing to NA with == returns NA Use is.na()
Row names silently dropped after subsetting Move IDs into a real column

Exercises

Short warm-ups. If any takes more than a minute, that’s the section of the cheat sheet to reread.

Q1 — Vector subsetting

Using x, produce: (1) the element named "c"; (2) all elements greater than 25; (3) every element except "a"; (4) the elements at positions 2 and 4.

Names go in quotes. A negative index drops that position. Several positions go inside c().

x["c"]           # named
x[x > 25]        # logical
x[-1]            # negative indexing
x[c(2, 4)]       # positional

Q2 — Data frame access, four ways

Extract the value column as a vector using four different syntaxes. Then run class() on df["value"] to see why it isn’t one of them.

df$value
df[["value"]]
df[, "value"]
df[, 2]

df["value"] and df[, "value", drop = FALSE] return a one-column data frame, not a vector. This distinction bites people constantly.

Q3 — Factors and reference levels

Turn g into a factor with WT as the reference level and the order WT → HET → KO → RESCUE, then confirm with levels(). Compare with what factor(g) does on its own.

levels = c("WT", "HET", "KO", "RESCUE")

gf <- factor(g, levels = c("WT", "HET", "KO", "RESCUE"))
levels(gf)

The default puts HET first, so every regression coefficient would be relative to HET instead of WT.

Q4 — Chain with the pipe

Using mtcars and the native pipe, write one pipeline that keeps cars with cyl == 6, selects mpg, hp and wt, sorts by descending mpg, and returns the top 3 rows.

filter(cyl == 6), select(mpg, hp, wt), arrange(desc(mpg)).

mtcars |>
  filter(cyl == 6) |>
  select(mpg, hp, wt) |>
  arrange(desc(mpg)) |>
  head(3)

Q5 — Write a function

Write mean_ci(x, level = 0.95) returning a named vector with the mean and the lower and upper bounds of a Normal-approximation confidence interval. Handle NAs.

Keep non-missing values with !is.na(x). The SE divides by sqrt(length(x)). The bounds are m - z * se and m + z * se.

mean_ci <- function(x, level = 0.95) {
  x  <- x[!is.na(x)]
  m  <- mean(x)
  se <- sd(x) / sqrt(length(x))
  z  <- qnorm(1 - (1 - level) / 2)
  c(mean = m, lower = m - z * se, upper = m + z * se)
}

Q6 — Read a formula

Without running anything, say what each formula means: (1) y ~ x + z, (2) y ~ x * z, (3) y ~ . - id, (4) log(y) ~ x - 1. Then check yourself: model.matrix() shows the columns R actually builds.

  1. y explained by main effects of x and z (no interaction).
  2. y explained by main effects and the x:z interaction.
  3. y explained by all other columns in data except id.
  4. log(y) explained by x with no intercept (the fitted log(y) is forced through 0 when x = 0).
