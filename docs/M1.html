1 · R foundations

Data frames, dplyr, ggplot2, broom, and getting spreadsheet data tidy

Course data (loads automatically; click to see the code)

R runs inside your browser. The first visit downloads R and the packages, which takes 20–40 seconds; after that the browser caches them. Wait for this block to finish before running exercises.

Almost everything in applied statistics in R starts by getting your data into a tidy data frame: one row per observation, one column per variable. Get that right and most of the ecosystem “just works”.

  • Base R and dplyr do the same jobs. Learn to read both: aggregate(y ~ g, data = df, FUN = mean) and df |> group_by(g) |> summarise(m = mean(y)).
  • ggplot2: a plot is data + aes() mapping + geoms (+ facets, scales, labels, theme). aes() maps columns to visual channels; anything constant (one colour for all points) goes outside aes().
  • Excel → R: readxl::read_excel() or read.csv() after exporting. Then pivot to long form (tidyr::pivot_longer()) and set factor levels yourself so WT is the reference.
  • broom: tidy() gives the coefficient table, glance() the model-level statistics, both as data frames you can stack and compare.

Start with flipper length vs body mass, no colour: one steep line. Colour by species: each species’ slope is shallower than the pooled one. Species differ in both variables, so pooling exaggerates the slope, which is the intuition behind adjusted associations in Module 4.

Exercises

penguins is already loaded. It has missing values, so remember na.rm = TRUE.

Q1 — Summaries two ways

Compute the mean, median and SD of bill_length_mm for each species, once in base R and once with dplyr. Confirm the numbers match.

Group by species. The formula interface of aggregate() drops rows with NA automatically; in summarise() you need na.rm = TRUE in each call.

aggregate(bill_length_mm ~ species, data = penguins,
          FUN = function(x) c(mean = mean(x), median = median(x), sd = sd(x)))

penguins |>
  group_by(species) |>
  summarise(
    mean_bill   = mean(bill_length_mm,   na.rm = TRUE),
    median_bill = median(bill_length_mm, na.rm = TRUE),
    sd_bill     = sd(bill_length_mm,     na.rm = TRUE),
    n           = sum(!is.na(bill_length_mm))
  )

Adelie ~39 mm, Chinstrap ~49 mm, Gentoo ~47 mm: bill length nearly separates Adelie from the other two but not Chinstrap from Gentoo.

Q2 — Three plots of flipper vs body mass

Make: (1) all points, one colour, with an overall linear smoother; (2) coloured by species with per-species smoothers; (3) as (2) but faceted by island. Write one sentence on what each plot adds.

p2 <- ggplot(penguins, aes(flipper_length_mm, body_mass_g, colour = species)) +
  geom_point(alpha = 0.7) +
  geom_smooth(method = "lm", se = FALSE)
p3 <- p2 + facet_wrap(~ island)
  1. Overall positive relationship: bigger flippers, bigger birds.
  2. Within each species the slope is much shallower than the pooled slope. Species differ in both flipper length and mass, so pooling exaggerates the slope (an aggregation effect, though not a full Simpson’s reversal).
  3. Species aren’t evenly spread across islands (Gentoo only on Biscoe, Chinstrap only on Dream), so any “island effect” is confounded with species.

Q3 — Write a describe() function

Return a one-row data frame with n (non-missing), mean, sd, median, IQR and n_missing, then apply it to every numeric column.

sum(!is.na(x)) counts non-missing values; sum(is.na(x)) counts missing ones.

describe <- function(x) {
  data.frame(
    n = sum(!is.na(x)), mean = mean(x, na.rm = TRUE), sd = sd(x, na.rm = TRUE),
    median = median(x, na.rm = TRUE), IQR = IQR(x, na.rm = TRUE),
    n_missing = sum(is.na(x))
  )
}

Q4 — Read a model with broom

Fit lm(body_mass_g ~ flipper_length_mm), then get the coefficient table and the model-level statistics. Interpret the slope in real units.

tidy(m)
glance(m)

Each extra millimetre of flipper is associated with about 50 g more body mass (slope ≈ 49.7 g/mm), and flipper length alone explains about 76% of the variance (R² ≈ 0.76). This is a marginal association, not causal and not species-adjusted; Q2 showed it pools several shallower within-species slopes.

Q5 — Western blot: spreadsheet to tidy, normalized data

data/western_blot_example.csv mirrors an Excel export after quantifying blots (one row = one lane × technical replicate). Inspect it, normalize to the loading control, average the three technical replicates within each biological replicate (you should get 16 rows), set WT as the reference, and make the dot plot you’d put in a paper.

Ratio = Target_Intensity / Loading_Control_Intensity; group by Genotype and Bio_Rep; levels c("WT", "HET", "KO", "RESCUE").

blot_bio <- blot |>
  mutate(Ratio = Target_Intensity / Loading_Control_Intensity) |>
  group_by(Genotype, Bio_Rep) |>
  summarise(Ratio = mean(Ratio), .groups = "drop") |>
  mutate(Genotype = factor(Genotype, levels = c("WT", "HET", "KO", "RESCUE")))
  • The biological replicate is the unit of replication: n = 4 per group, not 12. Treating technical replicates as independent inflates n and gives a bogus test. In Module 8 the clustering is modelled with a biological-replicate random intercept instead.
  • RESCUE should sit back near WT and KO be clearly reduced. Eyeballing this before any test is a sanity check that the code did what you expected.
